# Example RO-Crates

RO-Crate is a packaging standard: a set of data files plus one metadata file,
`ro-crate-metadata.json`, that describes them and how they relate.

This folder holds example crates for each handover in the bioprospecting
cycle. Each handover has at least one crate that satisfies its contract and
one deliberately broken crate, so that the checking agents have something to
pass and something to fail against.
